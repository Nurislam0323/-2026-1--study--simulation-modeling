Ross model

Finite-population repair system

Цель

Смоделировать систему с основными машинами, резервом и ремонтными устройствами, а затем сравнить среднее время до падения системы с аналитическим решением.

Подготовка

using DrWatson
@quickactivate "project"

using CSV
using Plots

include(srcdir("DESModels.jl"))
Main.DESModels

Параметры модели

p = DESModels.RossParams(; machines = 10, spares = 3, repairers = 1, runs = 200, seed = 150)
Main.DESModels.RossParams(10, 3, 1, 0.01, 1.0, 200, 150)

Запуск симуляции

results, path = DESModels.simulate_ross(p)
summary = DESModels.summarize_ross(results, p)
path_metrics = DESModels.ross_path_metrics(path, p)

CSV.write(datadir("ross_runs.csv"), results)
CSV.write(datadir("ross_path.csv"), path)
CSV.write(datadir("ross_summary.csv"), summary)
CSV.write(datadir("ross_path_metrics.csv"), path_metrics)
summary

Вывод

Модель Росса показывает, как резервирование и ремонт влияют на время до отказа системы. Аналитическое решение используется для проверки среднего времени до падения.
