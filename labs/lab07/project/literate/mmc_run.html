M/M/c model

Discrete-event simulation

Цель

Выполнить дискретно-событийное моделирование системы массового обслуживания M/M/c и сравнить результаты симуляции с аналитическими характеристиками.

Подготовка

using DrWatson
@quickactivate "project"

using CSV
using DataFrames
using Plots

include(srcdir("DESModels.jl"))
Main.DESModels

Параметры модели

p = DESModels.MMcParams(; lambda = 0.9, mu = 0.5, servers = 2, customers = 1000, seed = 123)
Main.DESModels.MMcParams(0.9, 0.5, 2, 1000, 123)

Запуск симуляции

events = DESModels.simulate_mmc(p)
summary = DESModels.summarize_mmc(events, p)

CSV.write(datadir("mmc_events.csv"), events)
CSV.write(datadir("mmc_summary.csv"), summary)
summary

Графики

plt_wait = plot(

    events.waiting_time,
    xlabel = "Customer",

Вывод

Модель M/M/c позволяет оценить ожидание, время пребывания в системе и загрузку каналов обслуживания. Аналитические характеристики используются как контроль для результатов имитационного эксперимента.
